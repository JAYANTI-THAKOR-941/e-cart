# React Component Practice — E-Cart

React practice project with card, counter and user-fetching components.

## Project structure

- `src/components/Card.jsx`
- `Counter.jsx`
- `FetchUser.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/e-cart.git
cd e-cart
```

Install Node.js and npm. Run `npm install` followed by `npm run dev`. Open the URL shown in the terminal.
